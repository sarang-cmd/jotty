Settings

Jotty has no account and no server. Everything on this page is stored in this browser profile and can be exported or deleted below.

Focus sessions

A session is one task with one clock. The task line is what every page gets judged against, so specific beats tidy.

Blocking rules

One domain per line. Subdomains are covered. In normal mode Jotty only delays a listed site when the page looks off task; in strict mode every listed site gets the delay.

Nudges

A nudge is the small card in the corner of the page. It names the drift and offers one way back. It does not close the tab for you.

Morning reflection

The next morning Jotty asks about the pages that did not belong to the task. Questions come from your own log, never from a template about "productivity".

Focus Player

Jotty searches YouTube through its own interface and plays the result in the privacy-enhanced embed, without the sidebar or the next-up queue. Search uses the official YouTube Data API with your own key. The key stays in this profile.

YouTube Data API key

Free quota is 10,000 units per day. One search costs about 101 units, so roughly 99 searches. Without a key the player still works with your channel list, but search is off.

Your data

The log holds domains, page titles, verdicts and minutes. It does not hold page content, keystrokes, form values or screenshots. Export is a readable JSON file.

Delete everything?

This removes the habit log, reflections, settings and the YouTube key from this browser. It cannot be undone. Type DELETE to confirm.
