01

The miss is eight seconds wide.

Most study drift does not look like procrastination. It looks like a reasonable click, followed by a page that is almost right.

Chapter 9 was open in one tab. The other tab was YouTube, opened for one stoichiometry video. The video was good. The sidebar under it was the problem.

By 16:06 the assignment was still on screen, but the video playing was about the chemistry of nonstick pans. That is chemistry. It is not gas stoichiometry. A blocker cannot make that distinction, which is why blockers get switched off during exam week.

Jotty is built around that distinction. It keeps YouTube, because YouTube is where the explanation often lives. It removes the hallway around it, asks you one honest question when you leave the task, and asks another one the next morning.

02

Three words decide it: title, address, channel.

The judge compares what the browser already knows about a page with the task you typed. No page body is read. The result is one of three calls, each with a different response.

Why not ask a language model?

Because this decision is small and repeatable, and because a study tool should work in a library with bad Wi-Fi. The judge is a deterministic comparison of the task line, the subject vocabulary and the page metadata. It runs in microseconds, it works offline, and you can read exactly why it made a call.

It is not perfect. When Jotty is wrong, the nudge has a This helps button, and the feedback stays on your device rather than disappearing into a dashboard you will never open.

The extension shows the same evidence you saw in the panel above: which words matched, which topic cluster the page belongs to, and how confident the call is.

The four judgements and what happens after each
Judgement When it happens What Jotty does
On task The page shares the task words, or sits in the same topic. Nothing. Time counts toward the task.
Related, off task Same subject, different topic. Teflon during gas stoichiometry. A nudge that names the gap and offers the way back.
Off task No link to the task in the title, address or channel. A nudge. A delay screen if the site is on your list.
No session No task is set, or the session has ended. Nothing is judged and nothing is logged.
03

The question is the product.

A report tells you that Tuesday at 16:00 is a weak spot. It does not tell you why. The next morning, Jotty asks about the actual pages, in the order they happened, and turns your answers into one adjustment.

Questions are written from your own log: the time, the site, the page title, the task that was open, and the pattern of the last four weeks. They are direct without being a lecture. There is no score, no streak to protect, and no red badge of shame.

One answer becomes a plan. If you say you drifted, Jotty suggests a soft block at the hour where it repeats. If you say you needed the video, it suggests searching inside the Focus Player instead of YouTube. If you say the break was planned, it leaves the break alone.

Why not just use YouTube search?

Because YouTube search is the doorway. Jotty searches for the task, ranks channels you marked as trusted, hides anything under ninety seconds, and plays the result in the privacy-enhanced embed with related videos turned off.

Search uses the official YouTube Data API v3 with your own key, called only from the extension's service worker. The free quota is 10,000 units a day; one search costs about 101. The interface tells you what you have spent instead of hiding it.

06

What runs where.

Jotty is a page judge, a local log and a small interface. There is no backend to trust because there is no backend. This section is the honest version of the privacy claim.

  1. 01

    Set one task

    Popup · 10 seconds

    A task line, a subject and an optional deadline. Everything after this is compared with that line, including tomorrow's questions.

  2. 02

    The content script reads three fields

    Isolated world · no page body

    Title, address, and the channel name on YouTube. It sends them to the extension's own service worker, which returns a verdict. No network request is involved.

  3. 03

    A nudge, or a delay

    Shadow DOM · dismissible

    Off-task pages get a corner card with the evidence and a way back. Listed sites can show a delay screen. Strict mode removes the override for the length of the session.

  4. 04

    The next morning

    Local reflection · one notification at most

    Flagged pages become three questions and one plan. Answers stay in the same storage object as the log, and the plan is a suggestion you can ignore.

Kept on this device

  • Task and session historyWhat you worked on, and when the session started and ended.
  • Domains, titles and verdictsThe log that produces the morning questions and the heatmap.
  • Minutes by domain and hourPruned after ninety days. Exportable as JSON.
  • Reflection answers and plansYour words, used only to suggest the next adjustment.
  • Settings and channel listsIncluding the YouTube API key, stored separately.

Leaves this device

  • Nothing, unless you search in the Focus PlayerThen the query and key go to googleapis.com, because that is the YouTube API.
  • The video request itselfMade by your browser to youtube-nocookie.com when you press play.
  • No analytics, no crash reports, no accountThere is no Jotty server to receive them.

Content scripts run on every http and https page so a session can judge the page you are on. With no session running, Jotty judges nothing and records nothing. The privacy policy lists every permission and why it exists.

07

Install in about a minute.

Jotty is not in the Chrome Web Store yet. Download the release, load it unpacked, and the toolbar icon is live. No build tools and no account.

  1. 01
    Download and unzip the release The archive contains a folder with manifest.json at its root.
  2. 02
    Open your browser's extension page Go to chrome://extensions (or brave://extensions, arc://extensions, edge://extensions) and turn on Developer mode.
  3. 03
    Choose Load unpacked Select the unzipped folder. Pin Jotty to the toolbar, open it, and type the task you are actually working on.
  4. 04
    Optional: add a YouTube key Settings → Focus Player. Search stays off until a key is added; everything else works without one.

?

Questions people ask before installing.

Does Jotty read the pages I visit?

It reads the title, the address and, on YouTube, the channel name. Not the body, not form fields, not passwords, not screenshots. Those three fields are compared locally with the task you typed.

The content script has to run on every page for that to work during a session. With no session running, it asks the service worker one question and stops.

Do I need a YouTube API key?

Only for search inside the Focus Player. The key is free from Google Cloud, lives in chrome.storage.local, and is read only by the service worker. One search costs about 101 of the 10,000 free daily units.

There is a step-by-step guide to creating the key. Everything else in Jotty works without it.

Does it block YouTube completely?

No, and that is deliberate. YouTube is where a lot of the explanation lives. Jotty keeps it available, judges each page against the task, and nudges when the page is related but off task.

If you want friction, add YouTube to the site list and turn on the delay. Strict mode removes the override for the length of a session. You can always end the session; the point is that ending it is a decision, not a reflex.

What happens if I ignore the nudge?

Nothing punitive. The time is logged as drift, and the page becomes one of the things Jotty asks about the next morning. Ignoring a nudge is data, not a failure.

Is it free?

Yes. Jotty is MIT licensed, has no ads, no paid tier and no account. There is nothing to subscribe to. If you use the Focus Player search, you pay Google in quota, not money, on the free tier.

Where is my data stored, and how do I delete it?

In chrome.storage.local in your browser profile. Settings → Your data exports a readable JSON file or deletes everything, including the API key. Uninstalling the extension also removes its storage.

Can I use it with a tutor, parent or study group?

Not yet. There is no sharing, no leaderboard and no remote dashboard. The log is local by design. If sharing exists later, it will be opt-in and it will be a file you choose to send.
