Create a free YouTube Data API key

9 minute read · Updated 29 October 2026Jotty field guide

Focus Player search uses the official YouTube Data API v3. You need a Google Cloud project, one enabled API and one key. The free daily quota is 10,000 units, and no billing account is required.

Before you start

You need a Google account. You do not need a credit card for the free quota used here, and you do not need to publish anything. The key is a string that identifies your project, not your Google account password.

1. Create a project

  1. Open console.cloud.google.com.
  2. Use the project selector at the top of the page and choose New project.
  3. Name it something you will recognize later, for example jotty-study. Location can stay as the default.
  4. Create the project and wait for the notification, then make sure it is selected.

2. Enable the YouTube Data API v3

  1. Open APIs & Services → Library.
  2. Search for YouTube Data API v3.
  3. Open it and press Enable.

If you enable the wrong YouTube API (there are older ones), search returns errors even though the key is valid.

3. Create the key

  1. Open APIs & Services → Credentials.
  2. Press Create credentials and choose API key.
  3. Copy the key. It starts with AIza.

4. Restrict it the right way

This is the step that breaks most browser extensions. Google offers "HTTP referrers" as the default restriction for website keys. A Chrome extension request has no HTTP referrer, so a referrer restriction produces a 403 even though everything looks correct.

  • Recommended: under API restrictions, choose Restrict key and select only YouTube Data API v3.
  • Leave application restrictions on None for a browser extension. There is no server IP to restrict and no referrer to match.
  • If you want extra safety, create a second key only for Jotty and delete it when you stop using the player.
A restriction by application type is not a security boundary here. The key is stored in your browser profile, and anyone with access to that profile can read extension storage. The API restriction and the daily quota are what limit the damage.

5. Add the key to Jotty

  1. Open the Jotty popup, then Settings → Focus Player.
  2. Paste the key into the API key field and press Save key.
  3. Press Test key. Jotty makes one channel lookup, which costs a single unit, and reports what came back.
  4. Check the quota readout. It should show one unit for the test.

The key is stored under a separate storage key, read only inside the extension's service worker, and never shown again in Settings. It is not included in the JSON export.

6. Understand the quota

CallUnitsIn Jotty
search.list100One search
videos.list1Views and durations for those results
channels.list1Key test, channel lookup

The free daily quota is 10,000 units, which is about 99 searches. Jotty caches a search for thirty minutes in the service worker, so repeating the same query does not spend quota again. Quota resets at midnight Pacific time.

Troubleshooting

"YouTube did not accept this API key"

Check that YouTube Data API v3 is enabled on the same project as the key, and that the key was copied without spaces.

"This key is restricted"

Remove the HTTP referrer restriction. Keep only the API restriction described in step 4.

"The YouTube quota for this key is used up"

Either the daily quota is spent or the project is shared. Wait for the Pacific midnight reset, use another project, or request a quota increase in Google Cloud (which is a paid form, not something Jotty can do).

"No results"

The query may be too narrow, or the results may lack an embeddable player. Jotty requests embeddable videos only. Try the task name without a chapter number.
