What Jotty stores, in plain language

6 minute read · Updated 29 October 2026Jotty field guide

There is no Jotty server. The entire product state is one JSON object in chrome.storage.local, plus a separate key for YouTube. Here is exactly what is in it.

The shape

Everything except the API key and the quota counter lives under one storage key, jotty.v1: 

{
  "version": 1,
  "settings": { ... },
  "session": {
    "task": "Gas stoichiometry, chapter 9",
    "subject": "Chemistry",
    "deadline": "2026-10-28",
    "startedAt": "2026-10-27T15:58:00.000Z",
    "endsAt": "2026-10-27T16:48:00.000Z",
    "status": "active",
    "taskUrl": "https://docs.google.com/document/d/ch9"
  },
  "habits": {
    "days": {
      "2026-10-27": {
        "hours": [{ "onTask": 0, "offTask": 0 }],
        "domains": {
          "youtube.com": { "seconds": 420, "onTask": 0, "offTask": 420 }
        },
        "flagged": 2
      }
    },
    "events": [
      {
        "ts": 1793117040000,
        "domain": "youtube.com",
        "title": "The chemistry of Teflon and nonstick pans",
        "verdict": "adjacent",
        "action": "nudged"
      }
    ]
  },
  "reflections": { ... },
  "feedback": [ ... ],
  "meta": { "installedAt": "..." }
}

The example is shortened. A full day has 24 hour buckets, and the event list is capped at 400 entries.

What is deliberately absent

No page text, no transcripts, no comments, no form values, no keystrokes, no screenshots and no account identifier. The judge only receives the title, address, channel and description meta tag for the moment it makes a call. The description is truncated to 600 characters and is not stored with the event.

The API key is separate

The YouTube key lives under jotty.youtube.key.v1. It is read only by the extension's service worker. The guard is enforced in code: calling the reader from a popup, options page or content script throws. Exporting data does not include it.

Retention

  • Days and events older than ninety days are pruned when new time is recorded.
  • Reflections are kept until deletion, because they are the history of your own decisions.
  • Search results are cached in memory for thirty minutes and are not written to storage.
  • Uninstalling removes the extension's storage, subject to browser cleanup.

The only two network requests

  1. A Focus Player search sends the query and key to www.googleapis.com.
  2. Pressing play loads the video from www.youtube-nocookie.com.

Both are started by you. Everything else runs in the browser. There is no analytics script, no crash reporter and no sync.

Inspect it yourself

  1. Open chrome://extensions and find Jotty.
  2. Press service worker to open the worker console.
  3. Run chrome.storage.local.get(console.log).

That prints the exact object described above. If a future version stores something new, this guide and the privacy policy are updated in the same commit.

Delete it

Settings → Your data → Delete stored data. Type DELETE to confirm. That removes the state, the key and the quota counter. There is no server-side copy to request, because there is no server.
